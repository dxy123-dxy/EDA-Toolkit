## 1. 要证明什么

| 问题 | 本期结论 |
|------|----------|
| 时空基础模型能否**跨区域**复用？ | **能。** BTHSA 预训练 → YRD Prompt，优于同预算从零训练 |
| 未观测空间补全能否压过经典插值？ | **本期未压过。** 邻站充足时 IDW/克里金仍更强 |
| 工程能否闭环？ | **能。** 训练脚本 + 同遮罩评估 + Demo + ETL `dl_infer` |

对外一句话：**跨场景讲 Prompt vs Scratch；单域空间填洞讲 IDW 作强基线；两者互补、不互相替代。**

## 2. 两类 Demo（怎么讲）

### D1 — 站点填图（未观测站点补全）

- **路径**：`output/phase2/demo_d1/`（图 + 指标 + README）
- **设定**：BTHSA，约 20% 站点 hold-out（seed=42）
- **结果（经典）**：IDW MAE/RMSE ≈ **8.4 / 11.3**；克里金 ≈ 9.8 / 12.6
- **同遮罩网格**：IDW 仍最优；UniST 误差更大（见目录内同遮罩表）
- **讲法**：展示「空间缺测 → 插值填图」基线能力；DL 不作本 Demo 主胜利叙事

### D2 — 面/网格补全 + 跨场景

- **路径**：`output/phase2/demo_d2/`
- **跨场景协议**（书面定义，验收用）：
  1. 区域 **A = BTHSA**：Stage-1 加长预训练（40 epoch，`TrafficKnowAirLong`）
  2. 区域 **B = YRD**：Prompt tuning（5 epoch，few_ratio=0.5）
  3. 对照：YRD **Scratch** 同预算从零；另在同一 occupied hold-out 格点上比 IDW/克里金
  4. **主指标**：YRD test **temporal RMSE / MAE**（Prompt vs Scratch）
- **结果**：Prompt RMSE/MAE ≈ **6.14 / 2.23**；Scratch RMSE ≈ **9.92**
- **同遮罩（YRD）**：IDW ≈ 4.0 / 5.7；UniST ≈ 17 / 21（纯空间补全仍输插值）
- **讲法**：先打出跨场景表，再诚实展示同遮罩对照，避免「全面碾压插值」表述

## 4. 复现与推理（验收命令）

环境：仓库根目录，使用 `.venv-ml`（见 [examples/phase2/README.md](../examples/phase2/README.md)）。

**两步：train → infer（或评估）**

```powershell
# Train（已跑通；权重在 third_party/UniST/.../model_best.pkl）
.\.venv-ml\Scripts\python.exe examples\phase2\run_unist_pretrain_long.py
.\.venv-ml\Scripts\python.exe examples\phase2\run_unist_prompt_cross.py --from-long --epochs 5 --also-scratch

# Infer / 指标（同遮罩对比表 + ETL）
.\.venv-ml\Scripts\python.exe examples\phase2\eval_same_mask.py --region yrd
.\.venv-ml\Scripts\python.exe -m eda_toolkit.cli.main operators execute dl_infer `
  -i output\phase2\tensors\knowair_bthsa_16x16_2022-01-01_2023-12-31.meta.json `
  -o output\phase2\op_dl_infer_bthsa `
  -p examples\config\dl_infer_bthsa_long.json

# 打包演示目录
.\.venv-ml\Scripts\python.exe examples\phase2\pack_demos.py
```

超参 JSON：`examples/config/dl_infer_*.json`；栅格/训练细节见 phase2 README。
