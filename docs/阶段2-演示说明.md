## 2. 两类 Demo（怎么讲）

### D1 — UniST 通用时空能力（官方论文数据）

- **路径**：`output/phase2/demo_d1/`
- **数据**：`E:\数据分析模型训练数据\data_release` → 联接/拷贝 `BikeNYC_short.json`、`TrafficHZ_short.json`
- **做法**：Stage-1 短训 → tube / temporal / block / random 重建指标 + 热力图
- **讲法**：证明「我们用的就是论文 UniST」；**不讲 IDW**

### D2 — UniST 跨城 Prompt（KnowAir 落地）

- **路径**：`output/phase2/demo_d2/`
- **协议**：BTHSA Long 预训练 → YRD Prompt（5 epoch）vs 同预算 Scratch
- **主指标**：temporal RMSE **6.14 vs 9.92**
- **附录**：同遮罩 occupied-grid 上 IDW 仍更强（另一张考卷，避免「全面碾压」表述）

## 3. 关键数字速查

| 实验 | 结论侧 | 数值 |
|------|--------|------|
| 跨场景 Prompt vs Scratch | **Prompt 胜** | temporal RMSE **6.14 vs 9.92** |
| BTHSA Long tube（KnowAir） | 预训练有效 | test tube RMSE ≈ **12**（冒烟 ≈95） |
| 官方 BikeNYC / TrafficHZ | D1 可演示 | 见 `demo_d1/metrics/paper_demo_*.md` |
| 同遮罩 YRD（附录） | IDW 更强 | RMSE ≈ **5.65**（UniST ≈20.8） |
