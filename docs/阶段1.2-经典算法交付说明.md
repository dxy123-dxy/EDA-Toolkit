## 2. 代码落点

```text
src/eda_toolkit/
├── algorithms/
│   ├── areal/
│   │   ├── weights.py          # Queen / Rook / KNN 空间权重
│   │   └── autocorrelation.py  # Moran / Geary / LISA / run_areal_analysis
│   ├── point_pattern/
│   │   ├── kde.py              # 高斯核密度估计
│   │   └── distance.py         # Ripley K/L/G + CSR
│   └── interpolation/
│       ├── idw.py              # 反距离权重
│       └── kriging.py          # 经验变异函数 + Ordinary Kriging
└── etl/
    └── registry.py             # 算子注册（含阶段 1.2 新增）
```

| 能力 | 核心函数 | ETL 算子名 |
|------|----------|------------|
| 面自相关 | `run_areal_analysis` / `moran_global` / `geary_global` / `lisa_local` | `areal_autocorr` |
| 点密度 | `kde_heatmap` | `point_pattern`（`kde=true`） |
| 点二阶统计 | `ripley_functions` | `point_pattern`（`ripley=true`） |
| 变异函数 | `empirical_variogram` | `variogram` |
| IDW | `idw_interpolate` | `idw` |
| 克里金 | `ordinary_kriging` | `kriging` |

依赖（可选 extras）：

- `[spatial]`：`libpysal` / `esda` / `pointpats`
- `[kriging]`：`pykrige`

## 3. 各模块做什么、产出什么

### 3.1 面数据 `areal_autocorr`

**做什么**：判断属性值在空间上是否聚集或离散；标出局部热点/冷点。

**主要参数**：`column`（必填）、`weight_type`（面默认 `queen`，点默认 `knn`）、`k`、`p_threshold`。

**典型产物**：

| 文件 | 含义 |
|------|------|
| `areal_summary.json` | 全局 Moran / Geary 与显著性 |
| `lisa_features.csv` | 每个要素的 Ii、p、聚类标签 |
| `lisa_map.geojson` | 带 LISA 字段的地图数据 |

### 3.2 点模式 `point_pattern`

**做什么**：一阶强度（哪里密）+ 二阶结构（相对 CSR 是否聚集/规则）。

**主要参数**：`kde`、`ripley`、`functions`（如 `["K","L","G"]`）、`n_simulations`、`support`、`kde_grid_size`。

**典型产物**：`kde_grid.csv` / `kde_grid.geojson`；`ripley_*.csv`；`point_pattern_summary.json`（含 CSR 推断摘要）。

### 3.3 插值 `variogram` → `idw` / `kriging`

**做什么**：先用变异函数看空间相关尺度，再用 IDW 或普通克里金估未观测位置。

**主要参数**：`column`（必填）；IDW 的 `power`、`grid_size`；克里金的 `variogram_model`、`leave_one_out_cv`。

**典型产物**：`variogram.json`；`idw_grid.*` / `kriging_grid.*`；克里金可选 `cv.rmse` / `cv.mae`。

## 4. 样例数据与流水线

| 文件 | 用途 |
|------|------|
| `examples/data/sample_polygons.geojson` | 4×4 面单元 + `gdp` / `pop`，跑 Moran/LISA |
| `examples/data/sample_events.geojson` | ~40 个点事件 + `pm25`，跑点模式与插值 |
| `examples/config/areal_gdp.json` 等 | 各算子参数模板 |
| `examples/run_phase12_pipelines.py` | 两条端到端流水线 |

**Pipeline A（面）**：`profile` → `areal_autocorr`  
**Pipeline B（点）**：`profile` → `point_pattern` → `variogram` → `idw` → `kriging`

```bash
pip install -e ".[dev,ui,spatial,kriging]"
python examples/run_phase12_pipelines.py
# 结果默认写入 output/phase12/
```

CLI 单算子示例见 [etl_operators.md](./etl_operators.md)。
